    About

    Understanding phishing attacks

    Phishing is a social engineering technique where attackers try to trick users into revealing passwords, financial information, or personal data through deceptive links, fake login forms, and lookalike websites.

    The goal of this project is to demonstrate how defensive, rule-based analysis can detect common warning signs in suspicious URLs before a user visits the site.
